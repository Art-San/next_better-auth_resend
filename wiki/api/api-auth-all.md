# Auth API

Путь: `src/app/api/auth/[...all]/route.ts`

## Назначение

Основной endpoint для аутентификации, использующий библиотеку `better-auth`. Обрабатывает все запросы, связанные с аутентификацией (вход, регистрация, выход, сессии и т.д.).

## Интерфейс

### Входные данные

- Запросы обрабатываются автоматически библиотекой `better-auth`.
- Поддерживает методы: `GET`, `POST`.
- Маршрут: `/api/auth/*` (catch-all route).

### Выходные данные

- JSON-ответы, соответствующие спецификации `better-auth`.
- Управление куками сессий.

## Логика работы (коротко)

Модуль экспортирует обработчики `GET` и `POST`, созданные с помощью `toNextJsHandler(auth)`. Конфигурация аутентификации импортируется из `@/lib/auth`. Это обеспечивает интеграцию `better-auth` с Next.js App Router.

## Где используется

- Используется клиентом `better-auth` на фронтенде для всех операций аутентификации.

## Примечания

- Конфигурация находится в `src/lib/auth.ts`.
- Использует Prisma Adapter.

## Источник изменений

- Автоматическая генерация
