# Set Password API

Путь: `src/app/api/auth/set-password/route.ts`

## Назначение

API-endpoint для установки пароля пользователя после верификации телефона.

## Интерфейс

### Входные данные

- `password` (string): Новый пароль пользователя.

### Выходные данные

- `success: true` при успешной установке пароля.
- `error: string` при возникновении ошибки.

## Логика работы (коротко)

- Проверяет авторизацию пользователя через `auth.api.getSession`.
- Получает новый пароль из тела запроса.
- Хеширует пароль с помощью `bcrypt`.
- Обновляет запись пользователя в БД с новым паролем.

## Где используется

- В компоненте `EnterCode` после успешной верификации SMS-кода.

## Примечания

- Использует `bcrypt` для хеширования пароля.
- Зависит от `better-auth` для управления сессией.

## Источник изменений

- Автоматическая генерация
