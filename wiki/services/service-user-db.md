# User DB Service

Путь: `src/server/prisma/prisma-user-db.ts`

## Назначение

Сервис для работы с пользователями (регистрация, вход) напрямую через Prisma.

## Интерфейс

### Входные данные

- `registerUser(email, password)`: Регистрация.
- `loginUser(email, password)`: Вход.

### Выходные данные

- `registerUser`: Возвращает созданного пользователя или ошибку.
- `loginUser`: Возвращает пользователя или ошибку.

## Логика работы (коротко)

- **registerUser**: Проверяет уникальность email, хеширует пароль (используя `hash.util.ts`), создает запись в БД.
- **loginUser**: Ищет пользователя по email, проверяет пароль.

## Где используется

- Ранее использовался в `api/login` и `api/register` (сейчас закомментировано).

## Примечания

- Дублирует функциональность `better-auth`.
- Использует кастомное хеширование паролей.

## Источник изменений

- Автоматическая генерация
