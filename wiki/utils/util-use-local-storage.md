# useLocalStorage Hook

Путь: `src/hooks/useLocalStorage.ts`

## Назначение

Кастомный React хук для синхронизации состояния компонента с `localStorage`. Обеспечивает реактивность между вкладками и внутри одной вкладки.

## Интерфейс

### Входные данные

- `key` (string): Ключ в localStorage.
- `initialValue` (T): Начальное значение, если в хранилище пусто.

### Выходные данные

- `storedValue` (T): Текущее значение.
- `setValue` ((value: T | ((val: T) => T)) => void): Функция обновления значения.

## Логика работы (коротко)

Использует `useSyncExternalStore` для подписки на изменения хранилища. При изменении данных (в том числе в других вкладках через событие `storage` или в текущей через кастомное событие `local-storage-change`) обновляет состояние компонента. Реализует кеширование распарсенного значения для оптимизации.

## Где используется

- В `LoginPage` и `UsersDB` для хранения/получения данных пользователя.

## Примечания

- Безопасен для SSR (возвращает `initialValue` на сервере).

## Источник изменений

- Автоматическая генерация
