# DB Connection Check

Путь: `src/server/utils/db-connection-check.ts`

## Назначение

Утилита для проверки соединения с базой данных.

## Интерфейс

### Входные данные

- Нет параметров.

### Выходные данные

- `Promise<void>`: Завершается успешно или выбрасывает ошибку.

## Логика работы (коротко)

Выполняет простой SQL запрос `SELECT 1` через Prisma. Если запрос падает, логирует ошибку и выбрасывает исключение.

## Где используется

- Может использоваться при старте приложения или в healthcheck-эндпоинтах (пока явного использования не найдено).

## Примечания

- Полезно для диагностики проблем с подключением.

## Источник изменений

- Автоматическая генерация
