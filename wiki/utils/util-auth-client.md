# Auth Client

Путь: `src/lib/auth-client.ts`

## Назначение

Клиентская инициализация библиотеки `better-auth`.

## Интерфейс

### Входные данные

- Конфигурация клиента (baseURL).

### Выходные данные

- Экземпляр клиента `authClient`.

## Логика работы (коротко)

Создает экземпляр клиента `better-auth` с указанием базового URL API. Используется для взаимодействия с API аутентификации на клиенте.

## Где используется

- Во всех клиентских компонентах, требующих аутентификации.

## Примечания

- `baseURL` жестко задан как `http://localhost:3000`.

## Источник изменений

- Автоматическая генерация
