# Database Client

Путь: `src/lib/db.ts`

## Назначение

Инициализация и экспорт экземпляра Prisma Client для работы с базой данных. Реализует паттерн Singleton для предотвращения множественных подключений в режиме разработки.

## Интерфейс

### Входные данные

- Переменная окружения `DATABASE_URL`.

### Выходные данные

- Экземпляр `PrismaClient` (экспортируется как `prisma`).

## Логика работы (коротко)

Использует `@prisma/adapter-pg` для подключения к PostgreSQL (Serverless-ready). Создает единственный экземпляр клиента и сохраняет его в глобальной переменной `globalThis` в режиме разработки, чтобы избежать исчерпания лимита подключений при Hot Module Replacement.

## Где используется

- Во всех серверных компонентах и API роутах, требующих доступа к БД.

## Примечания

- Использует Prisma Adapter for PostgreSQL.

## Источник изменений

- Автоматическая генерация
