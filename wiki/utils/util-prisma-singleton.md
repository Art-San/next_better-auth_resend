# Prisma Singleton

Путь: `src/server/prisma/prisma-singleton.ts`

## Назначение

Реализация паттерна Singleton для Prisma Client. Дублирует функциональность `src/lib/db.ts`, но находится в другой директории.

## Интерфейс

### Входные данные

- Переменная окружения `DATABASE_URL`.

### Выходные данные

- Экземпляр `PrismaClient` (экспортируется по умолчанию).

## Логика работы (коротко)

Инициализирует Prisma Client с адаптером PostgreSQL. Сохраняет экземпляр в глобальной переменной для переиспользования в dev-режиме.

## Где используется

- В `src/server/utils/db-connection-check.ts` и `src/lib/auth.ts`.

## Примечания

- Рекомендуется унифицировать использование клиента БД (выбрать либо `src/lib/db.ts`, либо этот файл).

## Источник изменений

- Автоматическая генерация
