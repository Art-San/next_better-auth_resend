# RegFormContext

Путь: `src/contexts/RegFormContext.tsx`

## Назначение

React Context для управления состоянием формы регистрации между разными шагами (страницами).

## Интерфейс

### Входные данные

- `children` (ReactNode): Дочерние компоненты.

### Выходные данные

- Провайдер контекста `RegFormProvider`.
- Хук `useRegFormContext`, возвращающий:
  - `regFormData`: Данные формы (email, password и т.д.).
  - `setRegFormData`: Функция обновления данных.
  - `resetRegForm`: Функция сброса данных.

## Логика работы (коротко)

Хранит данные формы регистрации в состоянии `useState`. Позволяет компонентам подписываться на эти данные и обновлять их.

## Где используется

- Обертка всего приложения (или части auth) для доступа к данным регистрации на разных страницах (`/register`, `/verify/*`).

## Примечания

- Клиентский компонент (`use client`).
- Использует типы и константы из `@/types/regFormData` и `@/constants/regFormData`.

## Источник изменений

- Автоматическая генерация
