# Prisma Schema

Путь: `prisma/schema.prisma`

## Назначение

Описывает модели данных, используемые в приложении, и их отношения. Является источником истины для генерации Prisma Client.

## Интерфейс

### Модели

- `User`: Модель пользователя.
- `Session`: Модель сессии `better-auth`.
- `Account`: Модель для OAuth-аккаунтов `better-auth`.
- `Verification`: Модель для токенов верификации `better-auth`.

### User

- `id`: Уникальный идентификатор.
- `email`: Уникальный email.
- `password`: Хеш пароля (опционально).
- `name`: Имя пользователя.
- `emailVerified`: Флаг подтверждения email.

### Session, Account, Verification

- Стандартные модели, используемые `better-auth` для управления аутентификацией.

## Логика работы (коротко)

Схема определяет структуру таблиц в базе данных PostgreSQL. Команда `prisma generate` использует эту схему для создания типизированного клиента `PrismaClient`, который обеспечивает безопасный доступ к данным.

## Где используется

- Во всем приложении для взаимодействия с БД через Prisma.

## Примечания

- Модели `Session`, `Account`, `Verification` являются стандартными для `better-auth` Prisma adapter.

## Источник изменений

- Автоматическая генерация
