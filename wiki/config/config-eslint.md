# ESLint Config

Путь: `eslint.config.mjs`

## Назначение

Конфигурационный файл для линтера ESLint.

## Интерфейс

### Входные данные

- Массив конфигураций.

### Выходные данные

- Экспортируемый объект конфигурации.

## Логика работы (коротко)

Использует стандартные конфигурации Next.js (`eslint-config-next/core-web-vitals` и `eslint-config-next/typescript`). Переопределяет стандартные исключения, чтобы включить `next-env.d.ts` в процесс линтинга.

## Где используется

- Используется ESLint для статического анализа кода.

## Примечания

- Используется новый "плоский" формат конфигурации.

## Источник изменений

- Автоматическая генерация
