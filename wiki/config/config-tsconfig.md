# TypeScript Config

Путь: `tsconfig.json`

## Назначение

Конфигурационный файл для компилятора TypeScript.

## Интерфейс

### Входные данные

- Настройки компилятора в `compilerOptions`.
- Списки включаемых (`include`) и исключаемых (`exclude`) файлов.

### Выходные данные

- Нет.

## Логика работы (коротко)

Определяет, как TypeScript должен компилировать код. Включены строгие проверки (`strict: true`), настроены пути импорта (`paths: { "@/*": ["./src/*"] }`) и плагин для Next.js.

## Где используется

- Используется компилятором TypeScript, редакторами кода (VS Code) и сборщиками (Next.js).

## Примечания

- Стандартная конфигурация для Next.js проекта.

## Источник изменений

- Автоматическая генерация
