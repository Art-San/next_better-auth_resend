# Login Page

Путь: `src/app/(auth)/login/page.tsx`

## Назначение

Страница входа в систему.

## Интерфейс

### Входные данные

- Нет пропсов.

### Выходные данные

- JSX форма входа.

## Логика работы (коротко)

Содержит форму с полями email и password. При отправке формы отправляет POST запрос на `/api/login`. При успехе сохраняет данные пользователя в localStorage через хук `useLocalStorage` и перенаправляет на `/users-db`. При ошибке отображает сообщение.

## Где используется

- Маршрут `/login`.

## Примечания

- Клиентский компонент (`use client`).
- Использует кастомную реализацию API, а не `better-auth` (судя по вызову `/api/login`).

## Источник изменений

- Автоматическая генерация
