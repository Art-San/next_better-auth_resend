# VerifyEmail Component

Путь: `src/app/(auth)/(reg)/_components/VerifyEmail.tsx`

## Назначение

Шаблон email-письма для подтверждения адреса электронной почты. Используется библиотекой `resend` для отправки писем.

## Интерфейс

### Входные данные

- `username` (string): Имя пользователя.
- `verifyUrl` (string): Ссылка для подтверждения email.

### Выходные данные

- HTML-разметка письма (с использованием компонентов `@react-email/components`).

## Логика работы (коротко)

Рендерит красивое HTML-письмо с приветствием, кнопкой подтверждения, альтернативной ссылкой и футером. Стилизация выполнена с помощью `Tailwind` компонента из `@react-email/components`.

## Где используется

- Используется в `src/lib/auth.ts` при настройке отправки писем через `better-auth`.

## Примечания

- Использует `@react-email/components`.
- Адаптивный дизайн письма.

## Источник изменений

- Автоматическая генерация
