# Verify Phone Page

Путь: `src/app/(auth)/(reg)/verify/verify-phone/page.tsx`

## Назначение

Страница для верификации номера телефона пользователя в процессе регистрации.

## Интерфейс

### Входные данные

- Нет пропсов.

### Выходные данные

- JSX разметка страницы верификации.

## Логика работы (коротко)

- Использует `useRegFormContext` для получения номера телефона.
- Отправляет SMS-код через `authClient.phoneNumber.sendOtp`.
- Отображает состояние загрузки, ошибки или компонент `EnterCode` для ввода кода.

## Где используется

- Маршрут `/verify/verify-phone`.

## Примечания

- Проверяет уникальность номера телефона перед отправкой кода.
- Использует `EnterCode` для ввода кода.

## Источник изменений

- Автоматическая генерация
