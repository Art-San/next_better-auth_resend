# AuthFormLayout Component

Путь: `src/app/(auth)/_components/AuthFormLayout.tsx`

## Назначение

Компонент-обертка (Layout) для форм аутентификации (регистрация, вход, восстановление пароля). Обеспечивает единый стиль оформления, центрирование на экране и наличие кнопки закрытия.

## Интерфейс

### Входные данные

- `children` (React.ReactNode): Содержимое формы.
- `variant` ('register' | 'default', optional): Вариант оформления. 'register' имеет большую ширину. По умолчанию 'default'.

### Выходные данные

- JSX разметка, оборачивающая дочерние элементы.

## Логика работы (коротко)

Компонент рендерит контейнер с затемненным фоном (`backdrop-blur`). Внутри находится белый блок с тенью, кнопкой закрытия (`CloseButton`) и переданным содержимым (`children`). Ширина блока зависит от пропса `variant`.

## Где используется

- Используется на страницах аутентификации, таких как `src/app/(auth)/login/page.tsx` и `src/app/(auth)/(reg)/register/page.tsx`.

## Примечания

- Использует `CloseButton` для навигации на главную.

## Источник изменений

- Автоматическая генерация
