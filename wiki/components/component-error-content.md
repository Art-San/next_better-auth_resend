# ErrorContent Component

Путь: `src/app/(auth)/(reg)/_components/ErrorContent.tsx`

## Назначение

Универсальный компонент для отображения сообщений об ошибках с возможностью действий (кнопок).

## Интерфейс

### Входные данные

- `error` (string | null): Текст ошибки.
- `icon` (ReactNode, optional): Иконка ошибки.
- `title` (string, optional): Заголовок ошибки.
- `primaryAction` (object, optional): Настройки основной кнопки (label, onClick, className).
- `secondaryAction` (object, optional): Настройки вторичной кнопки (label, onClick, className).

### Выходные данные

- JSX разметка блока ошибки.

## Логика работы (коротко)

Отображает иконку, заголовок и текст ошибки. Если переданы `primaryAction` или `secondaryAction`, рендерит соответствующие кнопки с обработчиками событий.

## Где используется

- Используется для отображения ошибок при регистрации или верификации email.

## Примечания

- Клиентский компонент (`use client`).

## Источник изменений

- Автоматическая генерация
