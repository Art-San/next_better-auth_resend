# EnterCode Component

Путь: `src/app/(auth)/_components/EnterCode.tsx`

## Назначение

Компонент для ввода SMS-кода при регистрации пользователя.

## Интерфейс

### Входные данные

- `phoneNumber` (string): Номер телефона пользователя.

### Выходные данные

- JSX разметка формы ввода кода.

## Логика работы (коротко)

- Отображает форму ввода 4-значного кода.
- При отправке проверяет код через `authClient.phoneNumber.verify`.
- После успешной проверки устанавливает пароль через `/api/auth/set-password`.
- Обновляет данные пользователя через `authClient.updateUser`.
- Перенаправляет на страницу входа после завершения регистрации.

## Где используется

- На странице `verify-phone/page.tsx`.

## Примечания

- Использует `useRegFormContext` для получения данных регистрации.
- Включает механизм ограничения попыток ввода кода.
- Использует таймер для ограничения частоты отправки кода.

## Источник изменений

- Автоматическая генерация
