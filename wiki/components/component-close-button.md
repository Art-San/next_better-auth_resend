# CloseButton Component

Путь: `src/app/(auth)/_components/CloseButton.tsx`

## Назначение

Кнопка закрытия модальных окон или форм аутентификации.

## Интерфейс

### Входные данные

- Нет пропсов.

### Выходные данные

- JSX кнопка с иконкой.

## Логика работы (коротко)

При клике вызывает `router.replace("/")`, перенаправляя пользователя на главную страницу. Использует `next/navigation`.

## Где используется

- В компоненте `AuthFormLayout`.

## Примечания

- Клиентский компонент (`use client`).

## Источник изменений

- Автоматическая генерация
