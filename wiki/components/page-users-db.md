# Users DB Page

Путь: `src/app/users-db/page.tsx`

## Назначение

Страница для отображения информации о текущем пользователе (тестовая страница).

## Интерфейс

### Входные данные

- Нет пропсов.

### Выходные данные

- JSX с именем пользователя.

## Логика работы (коротко)

Получает данные пользователя из localStorage (ключ 'user') через хук `useLocalStorage` и отображает имя пользователя или "нет", если данных нет.

## Где используется

- Маршрут `/users-db`.

## Примечания

- Клиентский компонент (`use client`).

## Источник изменений

- Автоматическая генерация
