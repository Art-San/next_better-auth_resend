# Register Page

Путь: `src/app/(auth)/(reg)/register/page.tsx`

## Назначение

Страница регистрации нового пользователя.

## Интерфейс

### Входные данные

- Нет пропсов.

### Выходные данные

- JSX форма регистрации.

## Логика работы (коротко)

Содержит форму с полями email и password. При отправке сохраняет данные в контекст `RegFormContext` и перенаправляет на страницу верификации `/verify/verify-email` (симуляция шагов регистрации).

## Где используется

- Маршрут `/register`.

## Примечания

- Клиентский компонент (`use client`).
- Использует `RegFormContext`.

## Источник изменений

- Автоматическая генерация
